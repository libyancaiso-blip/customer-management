منظومة صخر العرب — الإصدار الرابع

1) قبل التحديث: افتح النسخة الحالية وأنشئ نسخة احتياطية JSON واحتفظ بها.
2) ارفع الملفات الستة إلى جذر مستودع customer-management في GitHub واستبدل الملفات القديمة ذات الأسماء المتطابقة. لا ترفع ملف ZIP نفسه.
3) افتح رابط GitHub Pages من Safari، وانتظر التحديث ثم أعد فتح التطبيق.
4) أول تشغيل: اختر رمزاً سرياً من ستة أرقام على الأقل. الرمز يحمي واجهة الدخول فقط، ولا يشفّر قاعدة البيانات.
5) البيانات الحالية محفوظة في قاعدة IndexedDB السابقة نفسها عند استخدام الرابط نفسه والمتصفح نفسه.
6) بطاقات العملاء تعرض جميع الحقول، ولكل بطاقة زر طباعة. توجد طباعة جماعية وطباعة المحددين ونتائج البحث.
7) للطباعة على iPhone: اختر طباعة، ثم استخدم نافذة طباعة Safari أو مشاركة PDF إذا أتاحها iOS.
8) النسخ القديمة: يدعم استعادة JSON الذي يحوي records، والنسخ الجديدة التي تحوي customers.
9) لا تتخلص من نسخة JSON القديمة؛ النسخ غير مشفّرة.
10) Face ID غير منفذ في هذا الإصدار: يتطلب تكاملاً موثوقاً مع النظام أو بنية مصادقة مناسبة.
11) إذا فقدت رمز الدخول، فلا توجد وسيلة استرداد مدمجة. لا تمسح بيانات الموقع قبل حفظ نسخ احتياطية.
12) للتحديث على iPhone قد يلزم إغلاق التطبيق وإعادة فتحه، أو إزالة أيقونة الشاشة الرئيسية وإضافتها من جديد لتحديث الصورة، دون مسح بيانات الموقع.
